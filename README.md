# R. Abinayan — Personal Portfolio

A responsive React + Vite personal portfolio based on the supplied resume and profile photo.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```

## Main files

- `src/App.jsx` — portfolio content and layout
- `src/index.css` — complete responsive design
- `public/profile.jpg` — supplied profile image
